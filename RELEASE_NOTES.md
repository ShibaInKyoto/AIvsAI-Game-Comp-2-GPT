A standalone native 3D game for Windows 10/11 (64-bit), with a Linux build included.

Explore an impossible night train, pack strange freight, evade the conductor, and turn the timetable to rearrange your route. Original procedural architecture, art-deco surfaces and ambient score; random and daily tickets; four relic effects; free delivery upgrades; four passenger stories, a dawn-platform epilogue, escalating endless services, persistent settings and personal bests.

Download **TheMidnightExchange-Windows.zip**, extract it and open **TheMidnightExchange.exe**. No engine installation or network connection is needed. Controls and strategies are included in READ_ME.md.

This release is built by GitHub Actions after simulation, physics/gameplay integration, and packaged Windows runtime checks. SHA-256 hashes accompany the ZIPs.
